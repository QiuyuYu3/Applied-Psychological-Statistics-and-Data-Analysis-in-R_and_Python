# Applied Psychological Statistics and Data Analysis in R and Python

A toolkit-style manual of applied statistics for students with a psychology, sociology, or neuroscience background. The code runs on a simulated example dataset, and some chapters let you run the R code directly in your browser.

Read it online: <https://qiuyuyu3.github.io/Applied-Psychological-Statistics-and-Data-Analysis-in-R_and_Python/>

The manual is a [Quarto](https://quarto.org/) book; every push to `main` rebuilds and publishes the website. To build it locally from the project folder:

```
quarto preview   # live preview in your browser
quarto render    # build the website into _book/
```

RStudio ships with Quarto, so you can also open the project in RStudio and click **Render**.
